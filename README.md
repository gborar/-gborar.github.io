# Mis plantas

App para cuidar plantas: cuidados por especie, registro de riegos y avisos para revisar la tierra.

Ábrela en Safari en https://gborar.github.io/plantas/ y añádela con Compartir › «Añadir a pantalla de inicio».

El código fuente y las pruebas viven en el repositorio privado `Claude-code-issues` (carpeta `plantas/`); aquí solo se publica la app. Tus plantas se guardan únicamente en tu dispositivo.
